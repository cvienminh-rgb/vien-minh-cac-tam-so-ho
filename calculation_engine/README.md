# Calculation Engine

Bộ máy tính toán là thành phần xác định, không phụ thuộc cách diễn đạt của LLM. Mỗi module cần mô tả công thức, quy ước, phiên bản quy tắc, kiểm tra đầu vào, thông báo lỗi và unit test cho trường hợp chuẩn/biên/ngoại lệ.

Chưa triển khai phép tính Bát Tự hoặc Tâm Số ở giai đoạn này vì cần xác nhận đầy đủ quy tắc đầu vào, lịch pháp và ngoại lệ.
