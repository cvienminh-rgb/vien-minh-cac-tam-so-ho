# Bộ Skills biên tập nội dung

Bộ này gồm 9 skill để viết, biên tập và kiểm tra nội dung tiếng Việt.

## Danh sách
- `sound-like-your-posts`: học giọng văn từ bài mẫu.
- `ban-the-AI-words`: loại bỏ từ sáo rỗng AI.
- `humanizer`: chỉnh nhịp câu và giọng văn tự nhiên.
- `fact-checker`: rà dữ kiện cần kiểm chứng.
- `red-pen`: chỉ ra tối đa 5 câu yếu.
- `anti-ai-style`: quy tắc viết ngay từ bản nháp.
- `auto-block-banned-words`: rà từ cấm theo `references/tu-cam.txt`.
- `self-critique`: chấm và tự sửa tối đa 3 vòng.
- `ban-the-AI-patterns`: loại bỏ cấu trúc câu rập khuôn.

## Cấu trúc
Mỗi skill có một thư mục riêng và file `SKILL.md`. Danh sách từ cấm nằm trong `references/tu-cam.txt`.

## Lưu ý
Các skill là hướng dẫn để trợ lý áp dụng khi được gọi trong môi trường có hỗ trợ skills; chỉ thêm file vào GitHub không tự động kích hoạt chúng trong mọi giao diện AI.
