# Kho tri thức

Lưu tri thức đã chuẩn hóa. Tài liệu có bản quyền hoặc nội dung riêng tư không đưa vào repository công khai nếu chưa có quyền phù hợp.

- `sources/`: metadata và chỉ mục nguồn; bản gốc có thể nằm ở kho private.
- `excerpts/`: đoạn trích kèm vị trí trang/đoạn.
- `bat_tu_manh_phai/`: tri thức Bát Tự Manh Phái.
- `tam_so_hoc/`: tri thức Tâm Số Học.
- `glossary/`: từ điển thuật ngữ.

Mỗi mục phải giữ source_id và locator.
